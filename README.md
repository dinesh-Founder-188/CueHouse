# Cue House — Global Creative Services & Creator Ecosystem

A high-performance, immersive web application for **Cue House** based on the interactive WebGL/Three.js architecture from Grail.

All original animations, WebGL shaders, Three.js 3D totems, physics simulations, sound design, spiral mechanics, and interactions are 100% preserved and fully functional.

---

## What Was Updated for Cue House

1. **Brand Identity & Typography**:
   - Signature Cue House interlocking architectural vectors (`Logo.svg`, `grail-mark.svg`, `Fav.svg`).
   - High-resolution Favicons (`Fav.png`, `Fav.svg`) and OpenGraph card (`OG.png`).
   - Page titles and meta tags updated for *Cue House: Global Creative Services & Creator Ecosystem*.

2. **The 4 Core Growth & Service Pillars**:
   - **`CRE` (Creative Studio)**: Cinematic vision. Design, direction, 3D & motion. 🎨
   - **`ENG` (Engineering)**: Robust architecture. Modern web platforms & custom apps. ⚡
   - **`GRW` (Growth & Reach)**: Audience acquisition. Influencer campaigns & audited ROAS. 📈
   - **`STR` (Strategy & Escrow)**: Milestone governance. Verified talent & delivery excellence. 🛡️
   - Reputation Tiers: *Onboarding → Verified → Partner → Elite*.

3. **3D Interactive Guild Avatars (Three.js Totems)**:
   - **The Producer** (`duck-web.glb`): Orchestrates complex shoots, budgets, and never misses a delivery deadline.
   - **The Director** (`cat-web.glb`): Uncompromising aesthetic standards. Transforms commercial briefs into cinematic art.
   - **The Architect** (`bear-web.glb`): Builds unshakeable digital products, scalable web apps, and custom 3D web systems.
   - **The Scout** (`rat-web.glb`): Discovers breakout influencer talent and negotiates authentic creator partnerships.
   - **The Strategist** (`frog-web.glb`): Audited ROI modeling, precision audience targeting, and high-converting campaign mechanics.
   - **The Executive** (`penguin-web.glb`): Clear milestone escrow, governance, and institutional client trust.

4. **Interactive Milestone Spiral (WebGL Bent Planes)**:
   - 8 verified creative project milestones across Creator Marketing, Video Production, Web Engineering, 3D Motion, and Escrow Governance.

5. **Visual Storytelling & Proof (Photography Cards)**:
   - Authentic editorial imagery showcasing Cue House services, creator directories, project management desk, and real handshake accountability (`story/01`–`05` in JPG and responsive WEBP).

6. **Interactive Onboarding Quiz**:
   - 8-question creative readiness diagnostic tailored to campaign goals, production formats, creator sourcing, and milestone timelines.

7. **Voice Garden & Debriefs**:
   - Direct audio reflections from verified creators, directors, and brands post-delivery.

## How to Run

### Option 1: Node.js (Recommended)
```bash
npm start
```
*or directly with Node:*
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000).

### Option 2: Python HTTP Server
```bash
python -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000).
